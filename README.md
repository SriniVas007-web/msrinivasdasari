# Srinivas Dasari — Personal portfolio

A responsive, accessible static portfolio showcasing customer-centric Solution Engineering leadership, professional experience, and customer outcomes. Content is based on the supplied resume.

## Preview

Run `python3 -m http.server 8080` and open http://localhost:8080.

## Edit

- `index.html`: content and page structure
- `style.css`: responsive design

No build step or application dependencies. Fonts load from Google Fonts, with system font fallbacks. Contact actions use email and professional profile links. No tracking or data collection.

The original resume is intentionally excluded from the source. Update resume-reported performance figures as experience changes.
